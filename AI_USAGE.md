#This backend project was developed with the assistance of Microsoft Copilot and ChatGPT.
AI was used in the following ways:

1. Code Explanation & Debugging
AI was used to: 
-Explain TypeScript, Prisma, and Node.js concepts.
-Clarify error messages.
-Suggest fixes for common backend issues.

2. Documentation Assistance
AI helped generate:
-data.md example data.
-API testing notes.
-Clarifications on REST structure and endpoint behavior.

3. Development Support
AI provided:
-Guidance on structuring controllers, services, and routes.
-Suggestions for improving readability and modularity.
-Help with understanding requireAuthentication and requireAuthorization logic.

4. Git & Workflow Support
AI assisted with:
-Understanding Git commands.
-Creating safe commits.

5. Limitations
-AI did not write the entire backend.
-All final code decisions, implementations, and testing were performed by the development team.
